# Security Policy

Thanks for helping keep Sentry Studio and its users safe.

## Reporting a vulnerability

Please report security problems **privately**, not in a public issue,
discussion or Discord channel.

1. Go to this repository's **Security** tab.
2. Click **Report a vulnerability**.
3. Describe the problem, how to reproduce it, and what someone could do with it.

Only the maintainers can see your report. We'll reply there, keep you updated
while we work on a fix, and credit you when it ships if you'd like.

## Supported versions

Security fixes go into the **latest release** only. If you're on an older
version, please update before reporting, and check whether the problem still
happens.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Older releases | No |
